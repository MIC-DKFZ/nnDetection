## Setup
1. Clone the git repository and run the download script.
2. Create a folder `${det_data}/Task035_KiTS21/raw` (not the upper and lower case letters) and place the data folder in there. The final folder structure should look like this

```
${data_data}
    Task035_KiTS35
        raw
            data
                case_00001
                case_00002
                ...
```

3. Run the `prepare.py` in the KiTS21 Projects folder of nnDetection.
